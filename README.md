# Smart To-Do List

A lightweight, responsive to-do list web app built with **HTML, CSS, and vanilla JavaScript**. Add tasks, mark them as complete, and remove tasks through a clean interface with a gradient background and simple animations.

## Features

- Add tasks with input validation
- Mark tasks as complete or incomplete
- Delete tasks
- Automatically renumber tasks after changes
- Responsive, styled interface with completion indicators and subtle animations
- No framework or package installation required

## Built With

- **HTML5** — page structure
- **CSS3** — layout, colors, and animations
- **JavaScript (ES6)** — task interactions and DOM updates

## Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/TakkellapatiPooja/To-Do-List.git
   ```
2. Open the project folder.
3. Open the HTML file in your browser, or open the folder in Visual Studio Code and use the Live Server extension.

No build step or package installation is required.

## How It Works

The app creates task elements dynamically in the browser. JavaScript handles adding, completing, deleting, and renumbering tasks.

> **Current limitation:** Tasks are kept in the page while it is open. They are not saved after a refresh or browser restart.
